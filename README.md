# Olajide Olamide Portfolio

A React portfolio built for GitHub Pages.

## Run locally

1. Run `npm install`.
2. Run `npm run dev`.
3. Open the address Vite prints.

## Publish

1. Create a new public GitHub repository.
2. Upload every file in this folder to the repository.
3. In the repository, open Settings then Pages.
4. Under Build and deployment, choose GitHub Actions.
5. Push to the `main` branch.

The public link will look like `https://YOURNAME.github.io/REPOSITORYNAME/`.

## Add a project

Open `src/projects.js` and copy one project entry. The list and count update automatically.
